#임용대비 #현대대수학 #총정리 #인덱스 #출제빈도

`_raw/교육대학원/현대대수학` 의 개념정리 노트와 필기노트(1주차~31절)를 임용고시 대비용으로 재구성한 위키의 출발점. 각 노트는 **정의 → 정리와 증명 → 반례 → 출제 포인트 → 연습(접기)** 구조로 통일했다.

### 1. 학습 지도

**군론 (1차 서답형의 주 무대)**
1. [[군의 정의와 기본 성질]] — 군 판정, 항등원·역원의 유일성, 위수, 필수 예와 반례
2. [[부분군과 순환군]] — 1·2단계 판정법, 중심·중심화군·정규화군, $|\langle a^s\rangle|=n/\gcd(n,s)$
3. [[대칭군과 치환]] — 순환치환 분해, $|\sigma|=\operatorname{lcm}$, 짝/홀, $A_n$, $D_n$
4. [[잉여류와 라그랑주 정리]] — 잉여류의 5가지 성질, 라그랑주와 그 역의 반례
5. [[정규부분군과 잉여군]] — 정규성 판정, 잉여류 곱셈의 잘 정의성, 단순군
6. [[준동형사상과 동형정리]] — 제1·2·3동형정리, 대응정리
7. [[군의 작용과 코시 정리]] — 궤도–등방부분군 등식, 류방정식, $p$-군
8. [[실로우 정리와 유한군의 분류]] — 실로우 3정리, 단순군 부정 3단 논법, 위수 $pq$
9. [[유한생성 아벨군의 구조 정리]] — 기본정리, 불변량 인자, 위수 $n$ 아벨군 개수
10. [[군의 열과 가해군]] — 조성열, 조르당–횔더, $G^{(k)}=\{e\}$ 판정

**환론 (계산형과 구성형이 섞여 나온다)**
11. [[환과 체의 기초]] — $\mathcal{R}1\mathcal{R}2\mathcal{R}3$, 단원, 부분환 판정법
12. [[정역과 표수]] — 영인자와 단원의 $\gcd$ 판정, 유한 정역은 체, 표수
13. [[정역의 분수체]] — 동치류 구성 4단계, 보편성질
14. [[다항식환과 인수분해]] — 나눗셈 원리, 인수정리, 아이젠슈타인, 원분다항식
15. [[아이디얼과 잉여환]] — 아이디얼 판정, 준동형사상의 기본정리, 소·극대아이디얼

### 3. 문제 유형별 공략 경로

| 문제 유형 | 접근 경로 |
| --- | --- |
| "군임을 보이시오" | 닫힘 → 결합 → 항등원 → 역원. 부분집합이면 1단계 판정법 한 줄 |
| "$X/Y\cong Z$ 를 보이시오" | 전사 준동형사상 만들기 → 핵 계산 → 제1동형정리 |
| "$N \trianglelefteq G$ 를 보이시오" | $gng^{-1}\in N$ 직접 확인, 또는 $N$ 을 핵으로 갖는 준동형 구성, 또는 지표 2 |
| "위수 $n$ 인 군은 단순군이 아니다" | 실로우 $n_p$ 나열 → $n_p=1$ 이면 종료 / 아니면 $\lvert HK\rvert$ 부등식과 $N[H\cap K]$ |
| "위수 $n$ 인 군은 아벨군이다" | 실로우로 정규부분군 확보 → 내부직접곱 판정 → 교환자부분군 소멸 |
| "위수 $n$ 인 아벨군을 모두 구하시오" | 소인수분해 → 각 지수의 분할 → 불변량 인자 정렬 |
| "치환의 위수/짝홀" | 서로소 cycle 분해 → $\operatorname{lcm}$ → 호환 개수 |
| "기약인지 판정하시오" | 2·3차면 해 확인 / 아이젠슈타인 / 유리근 정리 / $\mathbb{Z}[x]$ 계수 비교 |
| "$\mathbb{Z}_n$ 의 단원·영인자" | $\gcd(m,n)=1$ 이면 단원, 아니면 영인자 |
| "아이디얼인지 판정하시오" | 덧셈부분군 확인 → 흡수 조건 $rn,nr\in N$ |

### 4. 자주 쓰는 반례 모음

- 순환군이 아닌 아벨군 : 클라인 4원군 $\mathbb{Z}_2\times\mathbb{Z}_2$
- 라그랑주의 역이 거짓 : $A_4$ (위수 12, 위수 6 부분군 없음)
- 부분정규열이지만 정규열은 아님 : $\{\iota\}\trianglelefteq\{\iota,\mu\}\trianglelefteq\{\iota,\mu,\rho^2,\mu\rho^2\}\trianglelefteq D_4$
- 정규성이 추이적이지 않음 : $\langle(1\,2)(3\,4)\rangle \trianglelefteq V\trianglelefteq A_4$ 이지만 $\langle(1\,2)(3\,4)\rangle\not\trianglelefteq A_4$
- $G/N$ 아벨이지만 $G$ 는 비아벨 : $S_3/A_3\cong\mathbb{Z}_2$
- 가해군이 아닌 최소 군 : $A_5$ (위수 60)
- 조성열이 없는 군 : $\mathbb{Z}$
- 해가 없어도 가약인 4차식 : $x^4+2x^2+1=(x^2+1)^2$
- 부분환이지만 아이디얼이 아님 : $F$ 안의 상수함수 전체, $\mathbb{Z}\subseteq\mathbb{Q}$
- 정역이 아닌 환의 잉여환이 정역 : $(\mathbb{Z}\times\mathbb{Z})/(\{0\}\times\mathbb{Z})\cong\mathbb{Z}$
