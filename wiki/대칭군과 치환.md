#대칭군 #순환치환 #호환 #교대군 #정이면체군 #치환의_위수

임용에서 **가장 계산 문제로 많이 나오는 단원**. 순환치환 분해 → 위수 계산 → 짝/홀 판정의 3단 콤보를 손이 기억하도록 연습해야 한다.

### 1. 치환과 대칭군

- **치환(permutation)** : 공집합이 아닌 집합 $A$ 에서 $A$ 자기 자신으로 가는 **전단사 함수**.
- **치환군** : $S_A$ = $A$ 의 모든 치환의 집합. 함수 합성에 대해 군을 이룬다.
- **대칭군** : $A=\{1,2,\dots,n\}$ 일 때 $S_A=S_n$, $|S_n|=n!$

> 증명 ($S_A$ 가 군임).
> ① 닫힘 : $f,g \in S_A$ 이면 $f\circ g$ 도 단사·전사이므로 $f\circ g \in S_A$.
> ② 결합법칙 : 함수 합성은 항상 결합적이다.
> ③ 항등원 : 모든 $a \in A$ 에 대해 $I_A(a)=a$ 인 항등치환이 $I_A\circ f=f\circ I_A=f$ 를 만족.
> ④ 역원 : $f$ 가 전단사이므로 역함수 $f^{-1}$ 이 존재하고 $f^{-1}\in S_A$.

- 표기 : 두 줄 표기법과 순환치환 표기법
$$\sigma=\begin{pmatrix}1&2&3&4\\2&3&1&4\end{pmatrix} = (1\ 2\ 3)$$
- **합성 방향 주의** : $\sigma\tau$ 는 관례상 $\tau$ 를 먼저 적용한다(오른쪽 → 왼쪽). 답안에 방향을 한 번 명시해두면 안전하다.
- $S_1=\{\varepsilon\}$, $S_2=\{\varepsilon, (1\ 2)\}$ 는 아벨군이지만 $n\ge3$ 이면 $S_n$ 은 **비아벨군**이다.
	- 반례 : $(1\ 2)(1\ 3)=(1\ 3\ 2)$, $(1\ 3)(1\ 2)=(1\ 2\ 3)$

### 2. 순환치환과 궤도

- **순환치환(cycle)** : $\sigma=(a_1\ a_2\ \cdots\ a_k)$ 는 $\sigma(a_1)=a_2,\ \dots,\ \sigma(a_{k-1})=a_k,\ \sigma(a_k)=a_1$ 이고 나머지는 고정. 길이 $k$ 인 cycle 이며 $|\sigma|=k$.
- **서로소인 순환치환** : 공통으로 움직이는 문자가 없는 두 cycle. 서로소인 cycle 끼리는 **교환 가능**하다.
- **궤도(orbit)** : $\operatorname{Orb}(a)=\{a,\sigma(a),\sigma^2(a),\dots,\sigma^{k-1}(a)\}$

**보조정리.** $b=\sigma^k(a)$ 인 $k$ 가 존재할 때 $b \sim a$ 로 정의하면 $\sim$ 는 $\{1,\dots,n\}$ 의 동치관계이고, $a$ 의 동치류는 $\operatorname{Orb}(a)$ 이다.
> 증명.
> ① 반사성 : $k=0$ 이면 $\sigma^0(a)=a$ 이므로 $a\sim a$.
> ② 대칭성 : $b=\sigma^k(a)$ 이고 $|\sigma|=n$ 이라 하면 $\sigma^{n-k}(b)=\sigma^{n}(a)=a$ 이므로 $a\sim b$.
> ③ 추이성 : $b=\sigma^i(a),\ c=\sigma^j(b)$ 이면 $c=\sigma^{i+j}(a)$ 이므로 $c \sim a$.
> $a$ 와 동치인 원소는 $a,\sigma(a),\dots,\sigma^{k-1}(a)$ 이므로 동치류 $=\operatorname{Orb}(a)$.

**정리(순환치환 분해).** 임의의 $\sigma \in S_n$ 은 서로소인 순환치환들의 곱으로 표현되며, 순서를 무시하면 그 표현은 유일하다.
> 증명.
> $A=\{1,\dots,n\}$ 에서 위 보조정리의 $\sim$ 를 생각하면 $\sim$ 는 동치관계이므로 $A$ 를 궤도들로 분할한다.
> $|\operatorname{Orb}(1)|=k_1$ 이라 하면 $\sigma_1=(1\ \sigma(1)\ \cdots\ \sigma^{k_1-1}(1))$ 을 얻는다.
> $\operatorname{Orb}(1)$ 에 속하지 않는 최소의 원소를 $a_2$ 라 하고 같은 방식으로 $\sigma_2$ 를 만들면 $\sigma_1,\sigma_2$ 는 서로소이다.
> 이 과정을 $|\operatorname{Orb}(1)|+\cdots+|\operatorname{Orb}(a_m)|=n$ 이 될 때까지 유한 번 반복하면 $\sigma=\sigma_1\sigma_2\cdots\sigma_m$.

- **핵심 계산 정리** : $\sigma$ 가 서로소인 cycle 들의 곱이고 각 길이가 $k_1,k_2,\dots,k_m$ 이면
$$|\sigma|=\operatorname{lcm}(k_1,k_2,\dots,k_m)$$

### 3. 호환과 짝/홀치환

- **호환(transposition)** : 길이 2인 cycle $(i\ j)$.
- 분해 공식 : $(a_1\ a_2\ \cdots\ a_k)=(a_1\ a_k)(a_1\ a_{k-1})\cdots(a_1\ a_3)(a_1\ a_2)$ → 길이 $k$ 인 cycle 은 $k-1$ 개의 호환의 곱.
	- 따라서 **cycle 의 길이가 홀수 ⟺ 짝치환**, 길이가 짝수 ⟺ 홀치환.
- **짝치환/홀치환** : 짝수 개의 호환의 곱이면 짝(우)치환, 홀수 개면 홀(기)치환.
- **정리** : 항등치환은 짝치환이고, 어떤 치환도 짝치환이면서 동시에 홀치환일 수는 없다. (부호 $\operatorname{sgn}$ 이 잘 정의된다.)

### 4. 교대군 $A_n$

- $A_n$ = $S_n$ 의 모든 짝치환의 집합. $A_n \le S_n$ 이고 $|A_n|=\dfrac{n!}{2}$ ($n\ge2$).

> 증명 ($|A_n|=n!/2$).
> $B_n$ 을 홀치환의 집합이라 하고 $f:A_n \to B_n$ 을 $f(\sigma)=(1\ 2)\sigma$ 로 정의한다.
> $f(\sigma_1)=f(\sigma_2) \Rightarrow (1\ 2)\sigma_1=(1\ 2)\sigma_2 \Rightarrow \sigma_1=\sigma_2$ → 단사.
> 임의의 $\tau \in B_n$ 에 대해 $\sigma=(1\ 2)\tau \in A_n$ 이고 $f(\sigma)=(1\ 2)(1\ 2)\tau=\tau$ → 전사.
> $S_n=A_n \cup B_n$, $A_n \cap B_n=\emptyset$ 이므로 $n!=|A_n|+|B_n|=2|A_n|$.
> $\therefore |A_n|=\dfrac{n!}{2}$
> (홀치환의 집합 $B_n$ 은 항등원을 포함하지 않으므로 군이 되지 않는다.)

- $(S_n:A_n)=2$ 이므로 $A_n \trianglelefteq S_n$ 이고 $S_n/A_n \cong \mathbb{Z}_2$ → [[정규부분군과 잉여군]]
- **$n\ge5$ 이면 $A_n$ 은 단순군이다.** ($A_5$ 는 위수 60의 최소 비아벨 단순군)
- $A_4$ 는 단순군이 **아니다** : 클라인 4원군 $V=\{\varepsilon,(1\,2)(3\,4),(1\,3)(2\,4),(1\,4)(2\,3)\}$ 가 정규부분군. 또한 $A_4$ 는 위수 6인 부분군을 갖지 않아 **라그랑주 정리의 역이 거짓**임을 보이는 표준 반례다.

### 5. 정이면체군 $D_n$

- $D_n$ = 정 $n$ 각형의 대칭(회전 $n$ 개 + 반사 $n$ 개)들이 이루는 군, $|D_n|=2n$, $D_n \le S_n$.
- 표현 : $D_n=\{1,r,r^2,\dots,r^{n-1},\ s,rs,r^2s,\dots,r^{n-1}s\}$
$$r^n=1,\quad s^2=1,\quad sr^i=r^{n-i}s$$
- $D_3=S_3$ (위수 6). $D_4$ 는 위수 8의 비아벨군.
- $n=4$ 의 구체적 원소 (정사각형 꼭짓점 $1,2,3,4$)
	- 회전 : $(1\ 2\ 3\ 4)$, $(1\ 3)(2\ 4)$, $(1\ 4\ 3\ 2)$, 항등
	- 반사 : $(2\ 4)$, $(1\ 3)$, $(1\ 4)(2\ 3)$, $(1\ 2)(3\ 4)$
- 대칭변환의 판정 기준 : 거리 보존, 즉 $\operatorname{dist}(i,j)=\operatorname{dist}(\sigma_i,\sigma_j)$ — **정 $n$ 각형의 대칭군을 구하라**는 유형이 자주 출제된다.

### 6. 출제 포인트

- $S_n$ 에서 **가능한 원소의 위수**는 $n$ 의 분할(partition)의 lcm 들. 예 : $S_7$ 에서 위수 12인 원소 존재 ⟸ $3+4$ 분할, $\operatorname{lcm}(3,4)=12$.
- **켤레 판정** : $\sigma,\tau$ 가 $S_n$ 에서 켤레 $\iff$ cycle 구조(cycle type)가 같다. 실제로 $\tau\sigma\tau^{-1}$ 은 $\sigma$ 의 각 문자에 $\tau$ 를 적용한 cycle 이다.
- $\sigma=(a_1\cdots a_k)$ 일 때 $\tau\sigma\tau^{-1}=(\tau(a_1)\ \cdots\ \tau(a_k))$ — 정규부분군 판정 계산에 그대로 쓰인다.
