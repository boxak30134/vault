#직접곱 #유한생성아벨군 #기본정리 #불변량_인자 #초등인자 #아벨군_분류

"위수 $n$ 인 아벨군을 모두 구하시오" 유형은 **기본정리 한 줄 + 분할 나열**로 끝난다. 계산 실수만 조심하면 확보 점수.

### 1. 직접곱

- **카테시안곱** : $\prod_{i=1}^{n}B_i=\{(b_1,\dots,b_n): b_i \in B_i\}$, 각 $B_i$ 를 인자(factor)라 한다.
- **직접곱(direct product)** : 군 $G_1,\dots,G_n$ 에 대해 $G=G_1\times\cdots\times G_n$ 에 성분별 연산
$$(a_1,\dots,a_n)(b_1,\dots,b_n)=(a_1b_1,\dots,a_nb_n)$$
을 주면 $G$ 는 군이 된다.

> 증명.
> ① 결합법칙 : 각 성분에서 결합법칙이 성립하므로 $(ab)c=a(bc)$.
> ② 항등원 : $e=(e_1,\dots,e_n)$ 이 $ae=ea=a$ 를 만족.
> ③ 역원 : $a=(a_1,\dots,a_n)$ 의 역원은 $(a_1^{-1},\dots,a_n^{-1})$.

- **위수 공식** : $|(a_1,\dots,a_n)|=\operatorname{lcm}(|a_1|,\dots,|a_n|)$, $|G_1\times\cdots\times G_n|=\prod|G_i|$
- 각 $G_i$ 가 아벨군이면 직접곱도 아벨군.
- $\bar H=\{(h,e)\}\trianglelefteq H\times K$ 이고 $(H\times K)/\bar H\cong K$ → [[정규부분군과 잉여군]]

**정리.** $\mathbb{Z}_m\times\mathbb{Z}_n$ 이 순환군 $\iff \gcd(m,n)=1$. 이때 $\mathbb{Z}_m\times\mathbb{Z}_n\cong\mathbb{Z}_{mn}$.
> 증명.
> 임의의 $(a,b)$ 에 대해 $|(a,b)|=\operatorname{lcm}(|a|,|b|)$ 이고 $|a| \mid m$, $|b| \mid n$ 이므로 $|(a,b)| \mid \operatorname{lcm}(m,n)$.
> 순환군이려면 위수 $mn$ 인 원소가 있어야 하므로 $mn=\operatorname{lcm}(m,n)$ 이 필요하고, $mn=\gcd(m,n)\operatorname{lcm}(m,n)$ 이므로 $\gcd(m,n)=1$.
> 역으로 $\gcd(m,n)=1$ 이면 $(1,1)$ 의 위수가 $\operatorname{lcm}(m,n)=mn$ 이므로 $\mathbb{Z}_m\times\mathbb{Z}_n=\langle(1,1)\rangle\cong\mathbb{Z}_{mn}$.

- 일반화 : $\mathbb{Z}_{n_1}\times\cdots\times\mathbb{Z}_{n_k}\cong\mathbb{Z}_{n_1\cdots n_k} \iff n_i$ 들이 쌍마다 서로소 (중국인의 나머지 정리)

### 2. 유한생성 아벨군

**정의.** 아벨군 $(G,+)$ 에 유한 부분집합 $S=\{x_1,\dots,x_n\}$ 이 있어 $G$ 의 모든 원소를 $S$ 의 원소들의 정수배의 합(선형결합)으로 나타낼 수 있으면 $G$ 를 유한생성 아벨군이라 한다.

**정리(유한생성 아벨군의 기본정리 — 초등인자 버전).**
임의의 유한생성 아벨군 $G$ 는
$$G \;\cong\; \underbrace{\mathbb{Z}\times\cdots\times\mathbb{Z}}_{r\text{개}}\times\mathbb{Z}_{p_1^{r_1}}\times\mathbb{Z}_{p_2^{r_2}}\times\cdots\times\mathbb{Z}_{p_t^{r_t}}$$
로 나타낼 수 있다. 여기서 $p_i$ 는 소수이고, 직접곱의 순서를 무시하면 이 표현은 **유일**하다.
- $r$ 을 **계수(rank, 베티 수)**, $p_i^{r_i}$ 를 **초등인자(elementary divisor)** 라 한다.

**정리(불변량 인자 버전).**
$$G\;\cong\;\underbrace{\mathbb{Z}\times\cdots\times\mathbb{Z}}_{r\text{개}}\times\mathbb{Z}_{d_1}\times\mathbb{Z}_{d_2}\times\cdots\times\mathbb{Z}_{d_k}$$
여기서 $d_i \ge 2$ 이고 $1\le i<k$ 에 대해 $d_i \mid d_{i+1}$ 이다. 이 표현은 $G$ 에 의해 유일하게 결정되며 $d_i$ 를 **불변량 인자(invariant factor)** 라 한다.

- 두 버전은 서로 변환 가능하다. 변환은 아래 표 방식으로 한다.

### 3. 위수 $n$ 인 아벨군 모두 구하기 (표준 절차)

1. $n$ 을 소인수분해 : $n=p_1^{e_1}\cdots p_k^{e_k}$
2. 각 $p_i^{e_i}$ 에 대해 지수 $e_i$ 의 **분할(partition)** 을 모두 나열
3. 소수별 선택을 조합 → 아벨군의 개수는 $\prod_i (\text{$e_i$ 의 분할 수})$

**예 : $n=8=2^3$** → 3의 분할 $3,\ 2+1,\ 1+1+1$ (3개)

| 초등인자 | 불변량 인자 |
| --- | --- |
| $\mathbb{Z}_8$ | $\mathbb{Z}_8$ |
| $\mathbb{Z}_4\times\mathbb{Z}_2$ | $\mathbb{Z}_2\times\mathbb{Z}_4$ |
| $\mathbb{Z}_2\times\mathbb{Z}_2\times\mathbb{Z}_2$ | $\mathbb{Z}_2\times\mathbb{Z}_2\times\mathbb{Z}_2$ |

**예 : $n=72=2^3\cdot3^2$** → $3$ 의 분할 3개 $\times$ $2$ 의 분할 2개 $=$ **6개**

| 2-성분 | 3-성분 | 불변량 인자 표현 |
| --- | --- | --- |
| $\mathbb{Z}_8$ | $\mathbb{Z}_9$ | $\mathbb{Z}_{72}$ |
| $\mathbb{Z}_8$ | $\mathbb{Z}_3\times\mathbb{Z}_3$ | $\mathbb{Z}_3\times\mathbb{Z}_{24}$ |
| $\mathbb{Z}_4\times\mathbb{Z}_2$ | $\mathbb{Z}_9$ | $\mathbb{Z}_2\times\mathbb{Z}_{36}$ |
| $\mathbb{Z}_4\times\mathbb{Z}_2$ | $\mathbb{Z}_3\times\mathbb{Z}_3$ | $\mathbb{Z}_6\times\mathbb{Z}_{12}$ |
| $\mathbb{Z}_2^3$ | $\mathbb{Z}_9$ | $\mathbb{Z}_2\times\mathbb{Z}_2\times\mathbb{Z}_{18}$ |
| $\mathbb{Z}_2^3$ | $\mathbb{Z}_3\times\mathbb{Z}_3$ | $\mathbb{Z}_2\times\mathbb{Z}_6\times\mathbb{Z}_6$ |

- **불변량 인자로 바꾸는 요령** : 각 소수별 인자를 지수 내림차순으로 오른쪽 정렬하여 열마다 곱한다. 가장 큰 것들끼리 곱한 값이 마지막 $d_k$.
- **$n$ 이 서로 다른 소수의 곱(square-free)이면 아벨군은 $\mathbb{Z}_n$ 하나뿐.**

### 4. 자주 묻는 따름 성질

- 유한 아벨군 $G$ 는 $|G|$ 의 **모든 약수 $d$ 에 대해 위수 $d$ 인 부분군을 갖는다** (라그랑주 정리의 역이 아벨군에서는 성립).
- 유한 아벨군에서 위수 $p$ 인 원소의 개수는 $p^m-1$ 꼴 ($m$ = $p$-성분의 인자 개수).
- $\mathbb{Z}_n$ 의 자기동형군 : $\operatorname{Aut}(\mathbb{Z}_n)\cong U(n)$, $|\operatorname{Aut}(\mathbb{Z}_n)|=\varphi(n)$
- 유한생성 아벨군이 **꼬임 없음(torsion-free)** $\iff \mathbb{Z}^r$ 과 동형
- 꼬임 부분군 $T(G)=\{a \in G : |a|<\infty\}$ 는 부분군이고 $G/T(G)$ 는 꼬임 없음.

<summary><b>연습 : 위수 $360$ 인 아벨군은 몇 개인가? (클릭)</b></summary>

$360=2^3\cdot3^2\cdot5$
- $2^3$ : 3의 분할 → $3,\ 2+1,\ 1+1+1$ → **3개**
- $3^2$ : 2의 분할 → $2,\ 1+1$ → **2개**
- $5^1$ : 1의 분할 → $1$ → **1개**

$\therefore 3\times2\times1=\mathbf{6}$ 개

가장 큰 불변량 인자가 $360$ 인 것(즉 $\mathbb{Z}_{360}$)은 유일하며, 이것이 위수 360인 유일한 **순환군**이다.
</details>
