## 브루소의 교수학적 상황론
1. 브루소의 교수학적 상황론
	1. 교수학적 상황
		1. 하나 이상의 문제-상황과 교사의 교수학적 의도가 담긴 상황(수업)
	2. 비교수학적 상황
		1. 학생이 스스로 탐구할 수 있도록 교수학적 의도가 감추어진 상황(스스로 공부)
	3. 교수학적 상황 -> 비교수학적 학습

2. 필요조건
	1. 책임의 양도
		1. 학습 책임 교사에서 학생으로 이동
		2. 학생에게 탐구, 발견 주도권 이양
		3. 폴리아, 스켐프가 강조한 독립 학습 핵심
	2. 교수학적 계약
		1. 교사, 학생의 수업 행동에 대한 상호 이해
		2. 각자의 역할, 책임 인식, 이행의 보완적 관계
		3. 계약 불이행시 딘즈 효과 발생? 이게 머야 
		-> 딘즈 효과 딘즈 참고하기
		딘즈 효과 : 애들이 게임이나 놀이를 하기는 하는데, 거기에 수학은 없는 경우 -> 메타인지-이동과 밀접한 연관
3. 발전과정 - 수학적 개념의 발생단계
	1. 원형 수학적 개념 단계
		1. 불완전하지만 일관된 관념
		2. 무의식적, 암묵적 사용
		3. 의식되지 않는 단계
	2. 의사 수학적 개념 단계
		1. 개념 연구 중
		2. 조직화 , 이론화 X
		3. 의미론적으로 조종
		4. 도구로 인식하는 단계
	3. 수학적 개념 단계
		1. 수학적 이론의 통제 하에 놓임
		2. 하나의 완전한 구조를 가지는 개념상태
		3. 이론적 수학 개념 정립 단계
4. 교수 상황 단계
	1. 행동 상황
		1. 원형 수학적 개념 형성
	2. 형식화 상황
	3. 타당화 상황
	4. 제도화 상황


## 쉐발라드의 교수학적 변환론
#### 지식의 정의
지식
- 학문적 지식
- <font color="#c00000">교수학적 지식</font>
	- 가르칠 지식
	- 가르쳐질 지식, 학습될 지식

#### 문제 의식
지식의 전달 : 원래 학문 -> 가르칠 지식 -> 가르쳐질 지식 으로 변환이 된다
- <font color="#c00000">교수 체계는 삼원적 관계</font>
	- 교사, 학생의 이원 관계만으론 설명 불충분
	- 지식을 포함한 삼원적 관계로 이해해야 함
	- 지식은 교사와 학생 사이에서 변형, 전달됨
- <font color="#c00000">지식의 파손성</font>
	- 가르치기 쉽게 하기 위해 원 의미가 훼손될 수 있음


#### <font color="#c00000">교수학적 변환론</font>
- 개인화/배경화(문맥화)
	- 자신만의 방식으로 지식 이해
	- 경험과 맥락을 활용해 지식 구성
- 탈개인화
	- 개인적 지식을 보편화 시키는 과정

일상적 지식 -> 학문적 지식 -> 가르칠 지식 -> 학습된 지식 -> 사용할 지식 -> 일상적 지식

우리가 배운 언어로 학생들에게 가르치는 게 도움이 된다. 대학 수학의 반대 과정으로 가르치는 게 도움이 된다.

#### 극단적 교수현상
- 메타인지-이동
	- 개인화 강조
	- 학생이 본질적 학습 내용에서 벗어남
	- 도구나 활동 자체에만 집중하는 현상
- 형식적 고착
	- 개인화 간과
	- 공식을 외우라고 강요
	- 형식적 지식만 강요
- <font color="#c00000">토파즈식 외면치레</font>
	- 탈개인화 강조
	- 발문처럼 보이지만 사실상 정답 유도
	- 교사가 답을 유도하며 학생은 수동적 반응
	- 형식적 이해만 있는 것처럼 보이는 현상
	- 학생은 근의 공식을 이해하지 못함
- <font color="#c00000">조르단식 외면치레</font>
	- 탈개인화 간과
	- 학생의 피상적 반응을 과대해석
	- 실제 이해 없이 성취로 착각하는 현상
	- 학생은 대입만 했을 뿐 이해 못함
	- 교사가 과도하게 해석하며 의미 부여

#### 인지적 장애의 종류
##### 인식론적 장애
- 일상어의 영향
	- 수학 용어와 일상어의 의미 차이
- 직관의 영향
	- 직관적 판단과 수학적 사실의 불일치
	- 감각적 경험이 논리적 이해 방해
- 과도한 일반화의 영향
	- 제한된 경험을 일반화하는 오류
- 은유의 영향
	- 수학 개념을 설명하는 은유적 표현
	- 형식적 정의로의 전환 중요
