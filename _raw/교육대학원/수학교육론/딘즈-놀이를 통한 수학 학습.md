### 딘즈의 개폐연속체(open-closed continuum)
#개폐연속체

- 열린 상태(Open)
	- 예비 학습 단계
	- 구체적 조작이나 놀이를 통해 다양한 경험을 하며 탐색하는 시기

- 닫힌 상태(Closed)
	- 형성된 개념을 분석, 적용하여 내면화하거나 체계적인 지식으로 묶는 완성의 단계
- 순환적 반복 : 닫힌 지식을 다른 새로운 상황에 적용(확장)하면서 다시 열린 상태가 되며 이 과정이 끊임없이 반복됨.


### 수학적 개념 형성 3단계
#예비놀이단계 #탐색형성단계 #표현단계
아동의 수학적 개념 학습 과정을 '놀이(구체적 조작)'를 중심으로 요약한 인지적 발달 단계. 아동이 수학이라는 추상적 지식을 곧바로 받아들일 수 없기 때문에 목적 없는 자유로운 조작에서 시작해 규칙을 깨닫고 이를 표현하는 세 단계의 순차적 흐름이 필수적이라고 보았음.

1. 예비 단계(예비놀이 단계)
	- 정의 : 목표 없이 구체물을 가지고 자의적으로 탐색하고 즐기는 자유 놀이의 시기
	- 행동 : 쌓기 블록(구체물)을 받았을 때, 도형의 성질을 공부하려는 생각 없이 단순히 높이 쌓거나 무너뜨리며 장난감처럼 다룸
	- 의미 : 수학적 학습이 시작되기 전 대상과 친숙해지고 무의식적 감각 경험을 쌓는 기초 토대가 됨.

2. 탐색형성 단계(구조화된 놀이 단계)
	- 정의 : 놀이 속에서 어떤 규칙성이나 제약이 필요함을 이해하고 *목적 지향적 탐색을 시작하는 중간 단계*
	- 행동 : 단순히 블록을 쌓던 아동이 "빨간색 다음에는 파란색을 놓아야 해" 라거나 "동그란 모양끼리 모아보자" 와 같이 스스로 규칙(게임의 법칙)을 부여하기 시작함.
	- 의미 : 아동에게 '느린 깨달음'이 일어나며 구체물들의 배치 속에서 수학적 구조와 공통적인 속성을 본격적으로 탐구하기 시작함.

3. 표현 단계(실습놀이 또는 연습게임 단계)
	- 정의 : 탐색을 통해 찾아낸 수학적 개념, 규칙성(공통성)을 **말, 글, 그림 등의 형태로 명확하게 나타내는 완성 단계**
	- 행동 : 여러 블록 중에서 찾아낸 규칙(예 : 사각형의 특징)을 "이 모양들은 모두 뾰족한 모서리가 4개씩 있어" 라고 말로 설명하거나 스케치북에 그림으로 그려서 표현
	- 의미
		- 갑작스러운 통찰을 통해 개념의 전체적 구조를 파악(게슈탈트 형성)
		- 자신이 이해한 개념을 내면화하여 완전히 고착시키는 단계

### 수학화 과정
#수학화_과정 
- 예비 단계
	- 1단계-자유놀이 : 목표나 제약이 없는 조작 활동 단계
- 탐색형성 단계
	- 2단계-게임 : 놀이의 규칙성에 대해 인식하는 시기, 모양의 차이나 유사성을 인식, 지식의 원형을 만들어가는 단계
	- 3단계-공통성 탐구 : 여러 가지 구체물, 패턴으로부터 공통적 수학적 성질(구조)을 찾아가는 단계
- 표현 단계
	- 4단계-표현 : 게임을 통해 얻은 구체적 경험을 그림이나 도식 등 보다 추상화된 표현으로 나타내는 단계
	- 5단계-기호화 : 자신만의 표현을 수학적 기호로 표현하여 높은 수준의 추상화를 구현해냄.
	- 6단계-형식화 : 수학적 구조 파악, 개념의 성질을 체계화(삼각형과 사각형의 관계, 삼각형의 성질, 사각형의 성질 등)

### 수학 학습의 원리
#역동적_원리 #구성의_원리 #수학적_다양성 #지각적_다양성
아동이 구체물 조작과 놀이를 통해 스스로 수학적 개념을 구성해 나갈 수 있도록 돕는 교수, 학습 지침. 피아제의 조작적 구성주의의 영향을 받음.
1. 역동적 원리(Dynamic Principle)
	- *"직접 만지고 움직이고 놀면서 시작해야 한다"*
	- 정의 : 수학적 개념 형성을 위해서는 학생들이 직접 참여하는 *역동적 활동과 놀이*가 시기적절하게 제공되어야 한다는 원리
	- 설명 : 수학 학습은 교과서를 보기만 하는 것이 아니라 단계적 정신 작용을 거쳐야 함. 딘즈의 개념 형성 3단계(예비놀이->구조화된 놀이->실습놀이)를 순서대로 제공하여 아동이 역동적으로 규칙을 찾아내도록 유도해야 함.

2. 구성의 원리(Contructivity Principle)
	- *"분석(공식화)하기 전에 먼저 직접 만들어보아야 한다."*
	- 정의 : 아동에게 수학적 상황을 제시할 때는 직관적 구성 활동이 선행되어야 한다는 원리
	- 설명 : 아동은 구체물을 가지고 스스로 무언가를 직접 만들어보고 채워나가는 직관적 활동(구성)을 먼저 해야만 개념을 더 깊이 이해할 수 있다.
	
3. 지각적 다양성의 원리(Perceptual Variability Principle)
	- 정의 : 동일한 수학적 개념을 지도할 때, 눈에 보이는 지각적 자료(구체물)을 최대한 다양하게 변형하여 제시
	- 설명 
		- '다중 구체화의 원리'라고도 함.
		- 3 의 개념을 가르칠 때, 바둑돌 3개만 계속 보여주기보다 사과 3개, 연필 3자루 등 시각, 촉각적으로 다른 매체를 다양하게 제공해야 물체의 재질, 모양에 집착하지 않고 '3'이라는 순수한 수학적 속성만 올바르게 추상화할 수 있다.

4. 수학적 다양성의 원리(Mathematical Variability Principle)
	- 정의 : 수학적 개념에 포함된 비본질적 변수(조건)는 다양하게 변화, 본질적인 핵심 변수는 고정하여 개념을 명확하게 이해시키는 원리
	- 설명
		- 학습자가 개념을 좁게 해석하지 않고 일반화할 수 있도록 돕는 전략
		- '평행사변형'에 대해 알려줄 때, '두 쌍의 대변이 평행하다'라는 본질적 성질은 그대로 둔 채, 변의 길이, 내각의 크기, 놓인 방향 등을 다양하게 바꾸어서 보여주어야 함. 그래야 특정한 모양의 평행사변형만 평행사변형이라고 오인하는 오개념을 방지할 수 있다.


| 원리      | 핵심       | 교실에서의 모습                                          |
| ------- | -------- | ------------------------------------------------- |
| 역동적 원리  | 놀면서 배우기  | 자유롭게 블록을 만지고 게임을 하며 활동성을 부여함                      |
| 구성의 원리  | 만들기가 먼저  | 공식을 외우기 전에 찰흙이나 종이로 도형을 먼저 만들어 봄                  |
| 지각적 다양성 | 재료를 다양하게 | 나무 블록, 플라스틱, 고무줄 등 다른 재질로 같은 개념을 보여줌              |
| 수학적 다양성 | 내용을 다양하게 | 크기를 키우거나 방향을 뒤집는 등 수학적 조건을 다양하게 하고, 본질은 변화시키지 않음. |



### 주의점:딘즈 효과(Dienes Effect)
- 아동들이 게임이나 놀이 자체는 즐겁게 참여하지만 그 안에 담긴 수학적 개념은 학습하지 못하는 현상
- 브루소(Brousseau)가 지적한 *메타인지적 이동*(Metacognitive shift)와도 연결되는 개념
- 도구나 활동이 본질적인 학습 내용을 가리지 않도록 주의해야함을 시사.



딘즈의 수학교수 원리 4가지
- 역동적 원리 : 수학을 본격적으로 배우기 전에 블록 등의 구체물을 사용하여 만지고, 놀아보며 수학의 원리를 몸으로 간접적으로 체험하도록 한다.
- 구성의 원리 : 학생들은 공식이나 성질을 먼저 배우는 것이 아니라 구체물을 사용하고 조작하여 수학적 성질을 추론해나가도록 한다.
- 지각적 다양성의 원리 : 가르치고자 하는 수학적 개념은 동일하게 제시하되, 학생들이 지각하는 구체물을 다양하게 제시하여 다양한 물체 속에서 동일하게 유지되는 수학적 개념을 파악하도록 한다.
- 수학적 다양성의 원리 : 가르치고자 하는 수학적 본질(ex.정삼각형)은 동일하게 유지하되 다른 수학적 조건들은 다양하게 변화시켜 제시(ex. 변의 길이를 달리 하기)하여 핵심이 되는 수학적 개념을 파악할 수 있도록 한다.
