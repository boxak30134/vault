#유의미_수용학습 #포섭
### 1. 유의미 수용학습이란 무엇인가
#학습과제의_논리적_유의미성 #관련_정착_아이디어 #유의미_학습태세 #잠재적_거리
오수벨의 유의미 수용학습(meaningful reception learning) 이란 학습자가 제시된 학습 자료로부터 새로운 의미를 습득하는 학습을 의미한다. 
- 정의 : 학습 내용이 학습자의 인지 구조 속에 있는 기존 지식과 **비임의적**이고 **실사적**으로 연결되어 그 안으로 **포섭**되는 학습을 의미한다.
- 수용 학습의 재고 : 오수벨은 '발견학습만이 유의미하다'라는 견해에 반론을 제기하며 교사가 지식을 체계적으로 전달하는 수용학습(Reception Learning)도 충분히 유의미할 수 있다 라고 주장하였음. 조건이 갖추어진다면 가장 효율적인 학습 방법이 될 수 있다 라고 하였음.
- 오수벨에 의하면 기계적 학습은 학습 내용이 학습자가 이미 소유한 인지 구조에 통합되지 않는 학습으로, 기존 지식과의 연계성 없이 기계적으로 암기하는 학습을 뜻한다고 한다. (스켐프의 [[Skemp의 수학교육 심리학과 지능 구조 이론#^de73de|도구적 이해]]와 맞닿아 있는 개념)
- 유의미 학습은 인지구조와 통합하여 인지구조의 변화가 일어나는 학습을 뜻한다.(스켐프의 [[Skemp의 수학교육 심리학과 지능 구조 이론#^3151ff|관계적 이해]], [[Skemp의 수학교육 심리학과 지능 구조 이론#^e4fba8|반영적 사고]]와 맞닿아 있는 개념)

### 2. 유의미 학습의 3가지 성립 조건
다음 세가지 조건 중 하나라도 부족하다면 기계적 학습이 일어날 가능성이 높아진다.
1) 학습 과제의 논리적 유의미성 : 학습 과제는 학습자의 인지 구조에 실사적이고 구속적으로 관련지어질 수 있다.
2) 학습자의 관련 정착 아이디어 : 학습자는 학습 과제와 관련이 있는 자신만의 지식을 소유해야 한다.
	1) 관련 정착 아이디어와 새로운 지식 사이의 거리를 잠재적 거리(Potential Distance)로 정의하였다.
	2) 잠재적 거리가 짧으면 학생들이 새로운 지식을 이해하고 습득하는데 도움이 된다. 잠재적 거리가 길면 학생들의 탐구 능력을 발달하는 데 유용하다고 한다.
3) 학습자의 유의미 학습 태세 : 학습자는 위의 첫번째 지식들을 실사적이고 구속적인 방식으로 자신의 인지 구조와 연결하려는 학습 자세를 가져야 한다.


### 3. 유의미 수용학습을 촉진하는 교수학습 전략
#포섭 

- **포섭** : 기존 지식(포괄적, 일반적, 추상적인 상위 개념)이 새로운 지식(포괄성이 낮고 구체적인 하위 개념)을 통합(포섭)해야 한다고 오수벨은 주장하였다.
- 인지구조의 위계성을 바탕으로 학습의 종류를 5가지로 분류하였다.
	1) 표현학습 : 명칭을 아는학습
	2) 개념학습 : 개념을 아는 학습
	3) 명제학습 : 개념 사이의 관계를 아는 학습
	4) 문제해결 학습
	5) 창의성
- 각 학습을 이루는 상위적 지식과 하위적 지식 사이의 관계가 어떻게 연결되느냐에 따라 
	- 하위적 학습(subordinate learning) : 기존의 포괄적인 개념 아래에 구체적인 사례를 포함시키는 방식
		- 파생적 포섭(derivative subsumption) : 단순히 기존 개념의 실례를 추가하는 학습
		- 상호관련적 포섭(correlational subsumption) : 새로운 정보가 기존 개념을 수정, 확대, 정교화하는 학습
	- 상위적 학습(superordinate learning) : 이미 알고있는 구체적인 아이디어들을 종합하여 더 포괄적인 새로운 개념이나 명제를 형성하는 학습
	- 병위적 학습(combinatorial learning) : 새 과제와 기존 지식이 수평적 관계를 유지하면서 서로 관련될 때 발생. 주로 유추나 모델을 통해 이루어진다.

으로 구분하였다.


### 4. 유의미 수용학습 이론을 적용한 수업 단계 및 절차
1. 선행조직자 제시(도입)
	1. 학습자가 이미 아는 것과 새로 배워야 할 것 사이를 잇는 '인지적 다리'역할을 하는 도입 자료
	2. 실제 학습 과제보다 높은 추상성, 일반성, 포괄성을 가져야 효과적이다.
