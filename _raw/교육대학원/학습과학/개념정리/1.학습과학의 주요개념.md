## 1. 학습과학의 정의

#### 1) 학습과학의 정의
인간이 어떻게 학습하는가를 과학적으로 연구하는 학문

#### 2) 학습이란 무엇인가?
**연습이나 경험**의 결과로 나타나는 비교적 **영속적**인 행동 혹은 행동잠재력의 변화

#### 3) 학습과학의 목표
- 학습이 일어나는 원리에 대한 연구 기반 모형의 정립
- 교육의 개선

#### 4) 학습과학의 준거(Criterion)
이론이 검증 가능한가

## 1. 전이(Transfer)

#### 1) 전이의 정의
- 새로운 학습이나 수행을 하는 데 있어서 선행학습의 효과가 나타날 때
- 전이가 일어나는 경우:
	- 선행학습을 통해 알게 된 사전 지식이
	- 새로운 과제에 대한 인간의 수행에 영향을 미친다.

#### 2) 전이의 측정
- 학습과제(Learning Task) : 연구 실험에서 사전에 주어지는 과제
- 전이과제(Transfer Task) : 실험에서 실제로 얼마나 잘 학습이 되었는가를 평가하는 과제
- 처치집단(Treatment Group) : 학습과제, 전이과제를 모두 수행하는 집단
- 통제집단(Control Group) : 전이과제만 수행하는 집단

#### 3) 전이의 세가지 유형
- 정적전이(Positive Transfer) : 처치집단이 통제집단보다 더 잘 수행
- 부적전이(Negative Transfer) : 통제집단이 처치집단보다 더 잘 수행
- 중립전이(Neutral Transfer) : 처치집단과 통제집단이 동등하게 수행

#### 4) 학습 결과의 평가방법

| 평가유형          | 평가목적   | 정의                                      | 사례                                     |
| ------------- | ------ | --------------------------------------- | -------------------------------------- |
| 파지(Retention) | 기억력 측정 | 제시된 학습내용을 회상(Recall)하거나 재인(Recognize)하기 | 수업에서 설명한 것에 대해서 기억나는 대로 적으시오.          |
| 전이(Transfer)  | 이해력 측정 | 학습한 내용을 새로운 상황에 활용하거나 평가하기              | 제시된 장치를 더욱 효과적으로 만들기 위해 어떻게 개선할 수 있을까? |


#### 5) 학습 결과의 세 종류

| 학습결과  | 인지적 기술     | 파지 평가 점수 | 전이 평가 점수 |
| ----- | ---------- | -------- | -------- |
| 무학습   | 지식 없음      | 낮음       | 낮음       |
| 암기학습  | 파편적 지식(파지) | 좋음       | 낮음       |
| 유의미학습 | 통합된 지식(전이) | 좋음       | 좋음       |
