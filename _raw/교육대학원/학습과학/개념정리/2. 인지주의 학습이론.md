## 인지주의에 대한 정의

#### 1) 행동주의와의 비교
1. 행동주의 : 학습자의 행동이 변화해야 학습이 이루어진 것이라고 보는 입장, 따라서 학습의 근거로 삼는 것은 외부에서 관찰 가능한 행동의 변화이다.
2. 인지주의 : 학습자의 지식, 인지구조가 변화해야 학습이 이루어진 것이라고 보는 입장, 따라서 학습의 근거로 삼는 것은 행동에서 추론되는 지식이다.

#### 2) 주요 원리
- 학습자는 능동적인 존재이다.
- 인간의 반응은 사전경험에 따라 다양하다.
- 학습은 행동잠재력의 변화까지 포함한다.

#### 3) 주요 이론
##### (1) Tolman의 잠재학습(Latent Learning)
- Tolman 의 실험 : 쥐를 세 집단으로 나누어 미로 탈출 실험 진행
	- 항상 보상 집단 : 매번 미로를 통과할 때마다 먹이 제공
	- 무보상 집단 : 미로를 통과해도 절대 먹이를 제공하지 않음
	- 지연 보상 집단 : 처음 10일간은 먹이를 주지 않다가 11일째부터 먹이 제공
- 실험 결과
	- 지연 보상 집단의 쥐들은 먹이 제공을 받기 전 다소 헤매는 듯한 행동을 보임
	- 11일차에 첫 보상이 주어진 직후, 항상 보상을 받았던 집단과 거의 동일한 수준으로 빠르게 미로를 탈출하였음.
	- 이는 보상이 없던 초기 10일 동안에도 쥐들은 미로의 공간적 구조를 이미 머릿 속에 학습하고 있었음을 뜻하고, 이는 [[#3) 주요 이론|학습은 행동잠재력의 변화까지 포함한다]]는 인지주의 학습 기본 원리와 일맥상통함. 11일째부터 먹이가 주어지자 잠재되어 있던 지식이 행동으로 표출된 것임.
- ##### 교육적 함의
	- 보상 없는 학습의 증명 : 보상을 받지 않는 상황에서도 미로 구조를 머릿 속에 그리는 Cognitive Map이 형성됨을 보여줌.
	- 수행과 학습의 분리 : 행동주의 이론에서는 학습 = 보상으로 강화된 행동 으로 보았으나 이 실험은 학습(내부적 이해)과 수행(외부적 표현)이 별개임을 증명하였음.

#### 2) Kohler 의 통찰학습(Insightful Learning)
- 통찰학습 : 문제 상황에서 관련이 없어 보이던 여러 요인이 갑자기 완전한 형태로 재구성되어 문제를 해결.
- 'Aha!' 현상을 경험.
- 침팬지가 주변 사물을 이용하여 천장에 매달린 과일을 따내는 것을 탐구한 실험이 유명함.
- 통찰 학습의 그래프는 시행착오 학습과 달리 완만하게 일어나지 않고 인지적 재구조화가 일어나기 전까지는 그래프가 평평하다가 **통찰이 일어나는 순간(A-ha Moment)** 수직에 가깝게 상승한다.
- 통찰이 일어나기 위한 조건 : 자극의 전체적인 관계를 파악할 수 있는 인지 능력이 있어야 가능하다.

#### 3) 정보 처리 이론(Information-Processing Theory)
- 정의 : 마음이 어떻게 지식을 처리, 저장, 인출하는지 기술하는 인지 이론
	- Atkinson-Shiffrin 의 기억 모형
	- 처리 수준 이론(Levels of processing theory)
	- 이중 부호 이론(Dual code theory of memory)
	- 멀티미디어 학습 인지 이론(Mayer's cognitive theory of multimedia learning: CTML)

##### 기억 저장소의 종류
###### 감각등록기(Sensory Register)
- 환경으로부터 들어온 자극, 정보를 원래 형태 그대로 잠시 보존하는 저장고
- 용량은 크지만 즉시 처리되지 않으면 정보는 금세 사라짐
- 지속시간: 1~4초
###### 작업기억(Working Memory)
- 지금 이 순간 활성화된 기억이 저장되는 저장소
- 의식적 사고가 일어나는 곳
	- 예 : 전화번호 외우기 / 구구단 암기
	- 지금 현재 생각하고 있는 것이 바로 작업기억 안에 있는 것.
- Miller's Magical Number 7 : 정보를 처리하는 능력에는 한계가 존재한다. 한 번에 처리할 수 있는 작업 기억은 7 개 정도(5개~9개)이다.
- 한계점
	- 정보 지속 시간 : 20초 ~ 30초
	- 제한된 용량
- 교육적 함의
	- 인지 과부하 줄이기
	- 불필요하거나 산만한 요소 제거하기
	- 복잡한 개념 작은 단위로 나누기
	- 정보를 구조화하기

###### 장기기억(Long-term memory)
- 정보가 최종적으로 저장되는 저장고
- 장기기억 저장소의 지속시간과 용량은 무제한이다.


##### 정보의 이동
- 지각(Perception) : 자극을 해석하고 의미를 부여하는 것, [[#감각등록기(Sensory Register)]]에서 [[#작업기억(Working Memory)|단기기억, 작업기억 저장소]]로 정보를 이동시킨다.
###### 부호화(Encoding)
- 새로운 정보를 [[#장기기억(Long-term memory)]]에 표상하는 과정
- 장기기억에 정보를 저장시키려면 반복(Repetition)과 정교화(Elaboration) 과정을 거쳐야 한다.
###### 인출(Retrieval)
- [[#장기기억(Long-term memory)| 장기기억]]에 저장된 정보를 [[#작업기억(Working Memory)]]으로 이동시키는 과정
- 정보를 장기기억에서 작업기억으로 이동시키려면 인출 단서를 활용하거나 (Retrieval Cue) 인출 연습을 많이 해야 한다.(Retrieval Practice)

##### 기억의 유형
###### (1) 선언적 기억(Declarative Memory)
- Knowing "what"
- 말로 표현됨
- 의식적인 주의가 필요함
- 명시적 기억(Explicit Memory) 라고도 함
- 일화기억(Episodic Memory)
	- 한 사람의 경험으로 구성되는 정신적 영상
	- 특정 시간, 장소와 관련됨
	- 개인적 경험
- 의미기억(Semantic Memory)
	- 보편적 지식이나 원리에 대한 지식을 담은 기억, 일반적 사실에 대한 기억
###### (2) 비선언적 기억(Non-declarative Memory)
- Knowing "how"
- 행동으로 표현됨
- 의식적 주의가 필요하지 않음
- 암묵적 기억(Implicit Memory) 이라고도 함
- 절차기억(Procedual Memory)
	- "어떻게 할 지" 아는 기억
	- 자전거를 타는 기술, 컴퓨터를 조작하여 게임을 실행시키는 일련의 과정
	- 책을 읽는 행위 등이 해당됨.
##### 중요한 개념
###### 주의(Attention)
- 다른 자극에는 신경 쓰지 않고 특정한 자극에만 신경 쓰는 것
- 선택적 주의(Selective Attention) : 제한된 주의 용량으로 인해 학습자는 특정한 자극에만 주의를 기울여야 한다.
- 주의 집중시키기(Gaining Attention)
	- 적절한 신호 사용하기(목소리, 몸짓, 반복, 특정한 자세)
	- 자료에 감정적 내용 증가시키기(유머)
	- 무엇이 중요한지 학생들에게 알려주기
###### Chunking
- 파편화된 정보를 기억하기에 용이하도록 그룹을 지어 학습하는 기술
- 조직화된 정보는 기억하기에 더 용이하다.
- 이미 알고 있는 것과의 관련성을 찾아 새로운 정보를 의미있게 만들기
- 정보를 덩어리로 외우면 한번에 외워야 하는 개수를 줄일 수 있다.

###### 대상영속성
- 눈 앞에 보이지 않는 대상을 머릿속에서 떠올리고 표상할 수 있는 능력
- 이것은 눈 앞에 보지 않고도 장기기억 저장소에 저장한 이미지, 영상을 인출할 수 있음을 뜻하므로 학습자의 장기기억에 해당 대상을 성공적으로 저장하였음을 보여주는 징표이다.

###### 망각과 기억
- 학습한 정보를 망각하는 이유
	- 작업기억의 정보가 장기기억으로 넘어가지 않은 경우
	- 시간이 지나면서 장기기억에 저장된 정보에 대한 접근성 저하
	- 인출단서 부족으로 인한 인출 실패
	- 간섭효과

###### 부호화 특수성(Encoding Specificity)
- 환경이 기억에 영향을 준다
- 학습 당시 상황과 비슷한 환경이 주어질 때, 그렇지 않은 환경에서보다 회상이 더 잘됨.(물리적 환경, 정서 상태), 즉 부호화 당시의 맥락과 이를 다시 떠올리는(인출)의 맥락이 일치할 수록 기억이 더 잘난다는 원리
- 오래 지속 가능한 기억을 위해서
	- 다양한 환경/상황에서 공부하는 것이 더 효과적이다
	- 하나의 특정 장소에서만 정보가 기억되기를 원하지 않는다면 다양한 장소에서 공부(다양한 맥락 학습)
	- 수 일에 걸쳐 다양한 장소에서 공부하기

###### 간섭(Interference)
- 기억 속에 있는 다른 정보 때문에 어떤 정보의 [[#인출(Retrieval) | 인출]]이 억제되는 현상
- 순행간섭(Proactive Inhibition)  : 이전의 지식이 새로운 지식의 학습에 방해가 되는 간섭
- 역행간섭(Retroactive Inibition) : 새로운 지식의 학습이 이전의 지식을 회상하는 것에 방해가 되는 간섭

###### 촉진(Facilitation)
- 순행촉진(Proactive Facilitation) : 이전 지식이 유사한 정보의 습득에 도움을 주는 촉진
- 역행촉진(Retroactive Facilitation) : 새로운 정보의 습득이 이전에 이미 구축되어 있던 지식을 향상시키거나 재구조화하는 촉진

###### 서열 위치 효과(Serial Position Effect)
- 여러 개의 정보가 나열되어 있을 때, 정보가 위치한 순서에 따라 기억의 정확도가 달라지는 현상
- 인간은 목록의 처음, 마지막에 나온 정보를 가장 잘 기억하고 / 중간에 위치한 정보는 가장 쉽게 잊어버리는 경향이 있다.
- 초두 효과(Primacy Effect)
	- 목록의 맨 처음 제시된 정보들을 더 잘 기억하는 현상
	- 처음 들어온 정보는 주의 집중도가 가장 높고, 머릿 속에서 시연(Rehearsal)할 수 있는 시간적 여유가 많아 [[#장기기억(Long-term memory)|장기기억]]으로 이동할 확률이 높기 때문
- 최신 효과 / 근접 효과(Recency Effect)
	- 목록의 맨 마지막에 제시된 정보들을 가장 정확하게 기억하는 현상
	- [[#작업기억(Working Memory) | 작업기억]] 에 방금 입력되어 중간에 들어온 정보보다 더 잘 기억할 확률이 높음.
- 교육적 함의 : 중요한 정보를 수업 초반에 제시하고 수업 후반부에 전체 요약하는 활동을 하는 것이 필요함.

###### 기계적 학습과 유의미 학습
- 기계적 학습(Rote Learning)
	- 새로운 학습 내용을 기존 인지 구조와 연결하지 않고 단순히 암기
	- 연결 방식 : 임의적 연결
	- 학습 특징 : 원리, 맥락을 이해하지 못하고 통째로 외우거나 반복해서 연습
- 유의미 학습(Meaningful Learning)
	- 학습자가 이미 가지고 있는 기존 지식과 실질적이고 비임의적으로 연결되는 학습
	- 연결 방식 : 실질적 연결. 새로운 정보가 기존의 인지 구조(스키마)에 녹아들어 지식이 확장됨.
	- 학습 특징 : 새로운 지식이 기존 지식 네트워크의 일부가 되고, 기존 지식의 범위가 확장됨.
